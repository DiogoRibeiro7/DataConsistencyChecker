# Checks catalog

This page is generated from the checker's registry each time the documentation is built, so it always matches
the installed version. Use the IDs with `execute_list` / `exclude_list`, `display_detailed_results(test_id_list=...)`
or the CLI's `--tests`. From Python, `DataConsistencyChecker().get_test_catalog()` returns the same information,
and `demo_test("CHECK_ID")` shows any check in action on synthetic data.
